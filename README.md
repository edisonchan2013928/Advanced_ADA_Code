# Introduction to Advanced_ADA_Code
This is the implementation of our paper "Complexity-Reduced Algorithms for Network and Network-Temporal Kernel Density Visualization", which is submitted to the VLDB Journal.

# How to Compile and Call Our Code?
In this Github link, there are two folders, namely NKDV and NTKDV, which store the code of our NKDV and NTKDV methods, respectively. In the NKDV (NTKDV) folder, there is a script file "compile_and_run_NKDV" ("compile_and_run_NTKDV"), which compiles and runs the code. Those input parameters of our code have been discussed in detail in each script file.

# Datasets
In our paper, we adopt four large-scale location datasets for conducting our experiments, which are:

Detroit 911 calls: https://data.detroitmi.gov/datasets/detroitmi::911-calls-for-service/about

San Francisco 311 calls: https://data.sfgov.org/City-Infrastructure/311-Cases/vw6y-z8j6

Chicago crime events: https://data.cityofchicago.org/Public-Safety/Crimes-2001-to-Present/ijzp-q8t2

New York pickup locations: https://data.cityofnewyork.us/Transportation/2014-Yellow-Taxi-Trip-Data/gkne-dk5s/about_data
