# Introduction to Advanced_ADA
This is the implementation of our paper "Complexity-Reduced Algorithms for Network and Network-Temporal Kernel Density Visualization", which is submitted to the VLDB Journal.

# How to Compile and Call Our Code?
In this Github link, there are two folders, namely NKDV and NTKDV, which stores the code of our NKDV and NTKDV methods, respectively. In the NKDV (NTKDV) folder, there is a script file "compile_and_run_NKDV" ("compile_and_run_NTKDV"), which compiles and runs the code. Those input parameters of our code have been discussed in detail in each script file.
